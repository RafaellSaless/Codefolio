# codefolio
Este é o repositório do meu site pessoal e portfólio, apelidado de Codefolio. O projeto foi construído com uma estética inspirada em ambientes de desenvolvimento (IDE) e terminais, refletindo minha jornada como estudante de Engenharia de Software.

💻 Sobre o Projeto
O Codefolio é um site estático desenvolvido para centralizar minhas informações profissionais, tecnologias que domino e projetos realizados. A interface conta com uma barra lateral de navegação e seções que simulam arquivos de código real.

🛠️ Tecnologias Utilizadas
O projeto foca na base sólida de desenvolvimento Web e automação visual:
HTML5: Estruturação semântica das seções.
CSS3: Estilização avançada

🎨 Design & Estética
O design foi pensado para ser familiar a qualquer desenvolvedor:
A janela de "avatar" e "sobre" possuem pontos simulando janelas de sistema operacional.
Dados são apresentados como se fossem um objeto real dentro de um editor de texto.
